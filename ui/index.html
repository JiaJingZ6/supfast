原理：原版 avs2bdnxml 每帧都要向 AviSynth 要一张全分辨率 RGBA 图（约 3~4 ms/帧），与画面有没有变化无关。 supfast 先解析 ASS 时间轴，把整条时间线切成「画面恒定段」与「画面变化段」：恒定段只渲染段首一帧整段共用，变化段逐帧渲染。 最后按 ASS 真实时间码重写 BDN XML，并把 PGS 的 PTS 重映射回真实时间。
注意：切段按「画面内容变化」切 —— 每一句新字幕都会单独成段，时间首尾相接的不同台词不会被合并，所以产出的 PNG 张数约等于字幕条数。 每段独立调用一次 avs2bdnxml（约 230 ms 固定开销），段数上万时加速比会下降，上限 20000 段。
依赖：本机需安装 AviSynth 2.5/2.6，渲染引擎由 mod 目录里的 avs2bdnxml.exe + csri\VSFilterMod.dll 提供。
