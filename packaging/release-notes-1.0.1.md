## supfast 1.0.1

把 ASS / SSA 字幕按「画面是否变化」切成段落，只为必要的帧渲染，输出可直接混流的 PGS `.sup` 与 BDN `.xml`。
这一版没有新的界面功能，主要是把 1.0.0 里几处会让结果不对、或者让人以为程序没反应的问题修掉。

### 下载

`supfast-1.0.1-win64.zip`（约 3.1 MB）— 绿色免安装，解压后双击 `supfast.exe`。
从 1.0.0 升级直接覆盖即可，`%APPDATA%\supfast-desktop\state.json` 里的设置与历史会保留。

- Windows 10 1803 以上 / Windows 11（64 位）
- 需要 WebView2 运行时：Win11 与新版 Win10 已自带；缺失时双击无窗口，装一次即可
- `mod\` 目录是字幕渲染引擎（avs2bdnxml + VSFilterMod），不能删

### 这一版修了什么

**会算错结果的**

- **非 ASCII 台词可能整段漏渲**：旧代码把 ASS 按 GB18030 猜解码，非 ASCII 字符一律变 `U+FFFD`，
  两条等长台词会算出同一个签名而被判成「画面没变」，其中一条就不渲染了。改为按系统 ANSI 码页解码。
- **SUP 的 PTS 重映射会静默截断**：某段越界时以前只是少写几个字节，现在直接报错并带段号与时间码。
- **重复点「开始转换」会起两个任务**：检查与置位不在同一次加锁里，两个并发请求都能通过，
  起两条线程往同一个输出目录写，产物互相覆盖。现在占位与置位在同一把锁内完成，取消标志也改成每任务一份。

**会让人以为程序没反应的**

- **双击两次只出第一个窗口**：第二个实例拿不到 WebView，`expect` 直接 panic，而发布版没有控制台，
  表现就是「双击没反应」。现在用命名互斥体拦在创建窗口之前，已有实例则把旧窗口恢复并置前。
- **窗口按钮点了不动**：Tauri 的 `core:default` 只含读类窗口权限，最小化 / 最大化 / 关闭需要显式授权，已补上。

**输出目录**

- 产物统一放进 `<目录>\<字幕名>\`：留空时是 `<字幕目录>\<字幕名>\`，选了目录就用它当父目录；
  选中的目录本身已叫字幕名时不再叠第二层。
- 输出目录不再从上次的运行里带出来，每次启动都是空的（默认值）；框下小字会显示这次的实际落点。

**性能与其他**

- 切段从 O(n²) 改成扫描线（事件按起点排序 + 活跃集合增量维护），长片分析更快。
- `SUP` 不再存三份拷贝，只记 `(类型, 起, 止)` 区间直接写盘。
- 临时目录改成随机名并独占创建，避免被预建同名 junction 重定向。
- `taskkill` / `explorer` 走 `%SystemRoot%\System32\` 绝对路径，不再受 PATH 影响。
- 帧率夹到 1–240、分辨率上限 8192，避免荒唐参数产出坏 SUP。
- 字幕目录里的相对路径、`\\?\` 前缀路径都能正确解析。

### 已知限制

- 没有安装包，是绿色目录；升级直接覆盖
- 双击标题栏不会最大化（右上角按钮正常）
- 右键菜单被关闭，输入框里请用 `Ctrl+V` 粘贴
