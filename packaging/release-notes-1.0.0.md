## supfast 1.0.0

把 ASS / SSA 字幕按「画面是否变化」切成段落，只为必要的帧渲染，输出可直接混流的 PGS `.sup` 与 BDN `.xml`。

一条 1 小时 44 分、1831 条事件的片子，实际只有 2.4% 的帧画面在变化。`avs2bdnxml` 逐帧渲染要跑 484 秒；
supfast 切段后只渲 1839 张 PNG，**102 秒**完成，产物与逐帧渲染逐像素一致。

### 下载

`supfast-1.0.0-win64.zip`（约 3.1 MB）— 绿色免安装，解压后双击 `supfast.exe`。

- Windows 10 1803 以上 / Windows 11（64 位）
- 需要 WebView2 运行时：Win11 与新版 Win10 已自带；缺失时双击无窗口，装一次即可
- `mod\` 目录是字幕渲染引擎（avs2bdnxml + VSFilterMod），不能删
- 首次启动是空白的：没有历史、没有最近、参数为默认值（23.976 / 1080p / 8 路并行）

### 这一版包含

**引擎**

- ASS/SSA 解析 → 按画面恒定切段 → 只在静态段渲首帧、动态段逐帧 → 重写 BDN XML 与 PTS
- 多窗口 Graphic 全部导出（同一帧有正文和注释时不会漏图）
- 单段 120 秒超时 + 3 次重试，失败会明确报出来而不是静默少帧
- 尾部冗余清屏剔除、SUP 流式落盘（不把整片攒在内存里）
- 子进程不分配控制台：整片从 270 秒降到 102 秒，也不再闪窗

**界面**

- 冷灰石墨中性色 + 单一强调橙，橙色只表示「这段需要逐帧渲染」
- 时间码统一 `HH:MM:SS:FF`（末位是帧）
- 切段刻度带做成仪表：灰块静态、橙块动态、悬停读出段号与时间范围
- 段表每行带「段条」，宽度等于该段占全片的帧数比例
- 主题三态：跟随系统 / 浅色 / 深色
- 七个高级开关对应 `avs2bdnxml` 的 `-p / -a / -b / -z / -e` 与「不生成 SUP」「只看计划」

**修过的问题**

- 关闭 WebView2 默认右键菜单
- 最小化 / 最大化 / 关闭按钮补齐窗口权限，失败不再静默
- 分析提示按「文件 + 内容」去重，改设置时不再反复弹同一条
- 启动不再自动选中上次的字幕，文件行留空
- 高级选项的七个开关铺满整行且不随窗口漂移；预设按钮文字垂直居中

### 已知限制

- 没有安装包，是绿色目录；升级直接覆盖
- 双击标题栏不会最大化（右上角按钮正常）
- 右键菜单被关闭，输入框里请用 `Ctrl+V` 粘贴
